# 我的收藏导航

一个简洁的静态导航页面，用于收藏和快速访问常用网站。

## ✨ 功能特性

- 🎴 **卡片式布局** - 每个链接显示为美观的卡片
- 🕐 **全屏沉浸式首页** - 时钟 + 西安天气居中主视觉（点击可刷新），GitHub 传送门、今日一言、时光进度、待办清单四角轻量融入
- ⚙️ **设置中心** - 侧栏顶部齿轮按钮：深色模式、动画效果开关、搜索回车聚焦首条、清除本地数据
- 📱 **移动端适配** - 抽屉菜单、触屏交互优化（无悬停场景全兼容），手机/平板/桌面全覆盖
- ✨ **交互动画** - 点击涟漪、按压反馈、组件错落入场、悬停微交互
- 📂 **可折叠侧栏** - 在线工具/网站收藏/影视收藏一级菜单默认收起、可折叠且记忆状态，小屋图标一键回首页
- 🎬 **影视收藏** - 番剧/电影/特摄/综艺/电视剧/纪录片海报墙，TMDB 统一评分与上映时间，支持评分/名称/上映时间排序，标题悬停滚动显示全名
- 🔍 **实时搜索** - 支持按标题和描述搜索
- 🏷️ **分类筛选** - 点击分类标签快速筛选
- 🌙 **暗色模式** - 支持明暗主题切换，自动保存偏好
- 📱 **响应式设计** - 适配桌面和移动端
- ⌨️ **键盘快捷键** - Ctrl/Cmd + K 聚焦搜索，ESC 清空搜索
- 🧰 **自建工具区** - 置顶展示自建网页工具（内置 SVG 可视化编辑器）

## 📁 项目结构

```
MySite/
├── index.html          # 主页面（首页仪表盘 + 三视图容器）
├── styles.css          # 样式（含深色模式/动画/响应式）
├── script.js           # 交互逻辑（视图管理/仪表盘/影视/设置）
├── data/
│   ├── links.json      # 网站收藏配置（分类 + 链接）
│   ├── tools.json      # 在线工具配置（驱动 tools/ 目录的 127 个自建工具页）
│   └── media.json      # 影视收藏配置（番剧/电影/特摄/综艺/电视剧/纪录片）
├── assets/media/       # 影视海报图（本地存储）
├── tools/              # 自建网页工具（每个工具一个目录，含 app.html）
└── README.md
```

## 🔧 使用方法

### 添加新链接

编辑 `data/links.json` 文件，在 `links` 数组中添加新条目：

```json
{
  "title": "网站名称",
  "url": "https://example.com",
  "description": "网站描述",
  "category": "分类名称",
  "icon": "🔗"
}
```

### 添加新分类

在 `data/links.json` 的 `categories` 数组中添加新分类名称。

### 添加影视记录

影视收藏（`data/media.json`）由站主自行维护，所有改动只需编辑该文件，刷新页面即生效。

```json
{
  "title": "作品名",
  "type": "番剧",          // 番剧 / 电影 / 特摄 / 综艺 / 电视剧 / 纪录片（与 types 数组对应）
  "status": "看过",         // 看过 / 在看 / 想看
  "rating": 8.5,           // 评分，统一取自 TMDB（themoviedb.org），不要自拟
  "release": "2022-04-09", // 上映时间（电视剧/综艺为首播日期），统一取自 TMDB
  "comment": "一句话短评，悬停海报显示",  // 可省略
  "cover": "assets/media/xxx.jpg",  // 海报图，建议存 assets/media/；省略时用类型渐变占位图
  "url": "https://www.themoviedb.org/tv/120089"  // 详情页链接，可省略
}
```

**增**：在 `items` 数组按上述格式添加一条；海报图下载放进 `assets/media/`。
**删**：删掉对应条目即可（不再使用的海报图片可顺手删除）。
**改**：直接编辑字段；排序在前端"排序"下拉中切换（评分/名称/上映时间），无需改数据。
**查评分与上映时间**：在 [themoviedb.org](https://www.themoviedb.org) 搜索作品，详情页评分即 `rating`（10 分制），电视剧取"首播日期"、电影取最早上映日期为 `release`。

排序说明：默认按评分降序；"按名称 A-Z"按中文拼音排序；"按上映时间"由新到旧。标题过长时悬停会自动左右滚动显示完整名称。

### 添加自建工具

自建工具为本站同源托管的网页（如 `tools/svg-editor/app.html`），展示在侧栏「在线工具」区，由 `data/tools.json` 驱动。

1. 新建 `tools/工具名/app.html`（页面随站点一同部署）；
2. 在 `data/tools.json` 的 `tools` 数组中登记：

```json
{"name": "工具名", "path": "工具名/app.html", "description": "一句话描述", "icon": "🔧", "category": "所属分类"}
```

分类会自动出现在侧栏「在线工具」下。

## 🚀 部署

本项目为纯静态页面，可通过以下方式部署：

- **GitHub Pages** - 推送到 GitHub 仓库后，在 Settings > Pages 中启用
- **Vercel** - 直接导入 GitHub 仓库
- **Netlify** - 直接导入 GitHub 仓库
