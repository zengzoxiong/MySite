游戏规则

玩法

  • 松手把果子丢进台面，两颗同种果子相触即融合成更大一档，得分按新果子计
  • 葡萄 → 樱桃 → 橘子 → 柠檬 → 猕猴桃 → 番茄 → 桃子 → 菠萝 → 椰子 → 半个西瓜 → 大西瓜
  • 落定的果子停在红色警戒线上方约 1.4 秒即判负，瓜堆越高越要精打细算
  • 合成大西瓜有专属彩蛋提示，游戏不会结束，继续冲击更高分

操作

  • 移动 / 拖动瞄准，松手落果；虚线是落点导引，「下一个」提前预告
  • 新游戏：随时重开一局（结算层与按钮均可）
