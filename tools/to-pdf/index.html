多格式转 PDF

把常见文件排成纸张，导出成 PDF 文件

两种导出方式，先选对再动手

打印 / 矢量 PDF（推荐）：走浏览器自己的打印，在打印对话框里目标选「另存为 PDF」。文字可选中、可搜索、可复制，中文不需要额外字体，文件也最小。

下载 PDF：点一下直接拿到 .pdf 文件。实现是把排版结果截图后逐页塞进 PDF（html2canvas + jsPDF），所以是位图版——文字不能选中，文件更大，胜在免对话框、能批量走。

两条路都在本机完成，不会把文件传上任何服务器。

能转什么

输入导出效果
docx连续排版（不强制 Word 分页），标题层级、表格、图片、字号与颜色尽量保留。
xlsx xlsm每个工作表一节，带底色、边框、合并单元格与数字格式（百分比、千分位、日期）。
md渲染成排版页面（标题、列表、表格、代码块、引用）；远程图片不会加载。
csv tsv转成表格，含引号转义解析。
json格式化缩进后按等宽字体输出；语法有错则按原文输出。
txt log 代码 xml yml ini等宽保留缩进与换行；UTF-8 解不动自动改用 GBK 并提示。
png jpg gif webp bmp svg按页面宽度缩放，单页输出。

设置项

  • 纸张 A4 / A3 / Letter，方向纵向 / 横向，页边距窄 12 mm / 标准 18 mm / 宽 25 mm，正文小 12px / 中 14px / 大 16px。
  • 预览区就是实际纸张尺寸，右上角实时显示「约 N 页」，改设置立刻重排。
  • 打印路径的 @page 尺寸与边距会跟着设置变，所以浏览器打印出来的分页和预览一致。

转不了的

  • pptx：幻灯片转 PDF 需要先有一个排版引擎把版式画出来，纯前端做不到，本站已不再支持 pptx 预览，也不提供转换。
  • doc / xls / ppt 等 Office 97-2003 二进制格式：需要服务端 LibreOffice，请先另存为 docx / xlsx。
  • 已经是 PDF 的文件：不做无意义的二次转换，直接用「文件在线预览」看。
  • 内容超过约 30000 像素高（几百页）时，下载路径会拒绝并让你改用打印，避免截图吃满内存。
