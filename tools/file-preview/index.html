文件在线预览

把文件拖进浏览器就能看，不用装任何第三方软件

关于这个工具

很多人收藏了 kkFileView 这类在线预览方案，但它要在服务器上装 Java、还要配 LibreOffice 才能把 Office 转成 PDF 来渲染。这个工具走的是另一条路：全部在浏览器里解析，文件不会上传到任何服务器，断网也能用。

能直接看的格式（PDF、图片、音视频、文本、JSON、CSV）走浏览器原生能力，零依赖；Office 与压缩包才会在你真正打开这类文件时，临时加载本站自带的解析组件（JSZip、docx-preview、SheetJS、marked），首屏不会多下一分钱流量。

支持范围

格式能到什么程度
pdf调用浏览器内置查看器，翻页、缩放、搜索、打印都在里面；浏览器被设置成「PDF 一律下载」时用右上角「新窗口打开」。
png jpg gif webp bmp ico avif svg原尺寸显示，透明背景用棋盘格衬底。SVG 以图片方式加载，里面的脚本不会执行。
mp3 wav flac ogg m4a / mp4 webm mov原生播放器，能放取决于浏览器是否带这个编码（H.264 的 mp4 一般没问题，HEVC 多数不行）。
txt log 代码文件等宽保留排版；可切换 UTF-8 / GBK / Big5 / Shift-JIS / EUC-KR / UTF-16 等编码，UTF-8 解不动时会自动改用 GBK 并提示。
json解析成可折叠的层级树，标出键名、字符串、数字与布尔；语法有错就退回纯文本并告知报错位置。
csv tsv自制解析（含引号转义），表头吸顶、行号列号齐全，超 5000 行只渲染前 5000 行。
md渲染成排版页面，放在禁脚本的隔离框架里，文中的脚本与远程图片不会被加载。
html htm默认显示源码，可一键切到「渲染成页面」，同样禁用脚本。
xlsx xlsm多工作表切标签，数字与日期按单元格格式显示。
docx尽量还原分页、页边距、页眉页脚、表格与图片；文本框、域代码和内嵌字体可能走样。
pptx按占位符坐标还原版式：字号、加粗、颜色与图片都会显示，位置继承母版与版式；动画、母版配色与艺术字不在纯前端还原范围内。
zip列出目录与大小，点任意一行即可预览里面的文本、图片、PDF 等成员。

看不了的格式，会告诉你为什么

  • doc / ppt 等 Office 97-2003 二进制格式：纯前端无解，需要服务端转换。工具会读出文件头确认类型，并提示你用 WPS / Office 另存为 docx / pptx 再拖进来（老 xls 可以读）。
  • HEIC 手机照片、PSD 图层、7z / rar 压缩包、CAD 与 3D 模型：分别需要 0.5～1.9 MB 的解码组件，为了首屏速度没有内置。
  • 单文件超过 200 MB 直接拒绝；文本只渲染前 400 KB；压缩包成员超过 50 MB 不解压。

隐私

文件通过 File 对象在内存里读取，只走 createObjectURL 与本地解析，页面不会发出任何包含文件内容的请求。你可以在浏览器开发者网络的 Network 面板里验证：除了本站自己的脚本与样式，没有第三条连接。
